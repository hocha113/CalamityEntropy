# Call of Void / 虚空召唤

**Call of Void** is an expansion mod for Terraria. It adds new bosses, unique weapons, accessories, pets, vanity sets, and distinct mechanics.

**虚空召唤**是泰拉瑞亚的流程拓展模组，添加了数个新 Boss、独特的武器与饰品、全新护甲重铸机制、宠物、时装等丰富内容，完全支持多人联机游玩。

---

## 模组特色 / Features

- **拓展流程**：独立且完整的流程拓展体验。
- **多人联机**：完全支持多人模式游玩。
- **全新首领（Bosses）**：包含巡游者、先知、虚无双子等多个独具挑战性的 Boss。
- **独特武器体系**：包含战士与法师系列武器、各职业特色武器以及独特的鞭子。
- **丰富配装与机制**：
  - 大量新增饰品与卡组体系
  - 可选的护甲重铸机制
  - 全新 Boss 血条样式
  - 可爱的全新宠物与开发者时装
  - 虚空马桶等趣味内容
